# 2042 TEAMタブ：チーム・選手データの入れ方

2042シーズンページの **「Teams」タブ**（球団一覧 → 各球団の詳細）に表示する
**チーム成績・選手成績**は、次のファイルを手で編集して埋めます:

```
src/data/jbu2042Teams.json
```

30球団分のキー（略称）が用意済みで、初期状態は空です。編集して保存し、
GitHubにpush（または/adminと同じくコミット）すると、サイトに反映されます。

---

## ファイルの形

各球団（キーは略称。例 `TOK`=東京ロイヤルファミリー）ごとに3つの枠があります:

```json
{
  "TOK": {
    "teamStats": { "打率": "", "本塁打": "", "得点": "", "盗塁": "", "防御率": "", "失点": "" },
    "batters": [],
    "pitchers": []
  }
}
```

- **teamStats**：チーム全体の成績。値を入れると詳細ページ上部に表示（空の項目は出ません）
- **batters**：野手の一覧（下記の形のオブジェクトを並べる）
- **pitchers**：投手の一覧

空のままなら、その球団の詳細ページに「準備中」と表示されます。

---

## 記入例（TOK を埋めた場合）

```json
{
  "TOK": {
    "teamStats": { "打率": ".271", "本塁打": "188", "得点": "721", "盗塁": "92", "防御率": "3.12", "失点": "598" },
    "batters": [
      { "name": "山田 太郎", "pos": "中堅", "avg": ".312", "hr": "34", "rbi": "98", "sb": "21", "ops": ".921" },
      { "name": "佐藤 次郎", "pos": "一塁", "avg": ".288", "hr": "29", "rbi": "104", "sb": "3", "ops": ".880" }
    ],
    "pitchers": [
      { "name": "鈴木 三郎", "w": "15", "l": "6", "era": "2.45", "g": "27", "so": "189", "sv": "0" },
      { "name": "高橋 守", "w": "3", "l": "2", "era": "1.98", "g": "62", "so": "78", "sv": "38" }
    ]
  }
}
```

### 項目名（キー）一覧
- **batters**：`name`（選手名）, `pos`（守備位置）, `avg`（打率）, `hr`（本塁打）, `rbi`（打点）, `sb`（盗塁）, `ops`
- **pitchers**：`name`（選手名）, `w`（勝）, `l`（敗）, `era`（防御率）, `g`（登板）, `so`（奪三振）, `sv`（セーブ）

> 値はすべて文字列（`"34"` のようにダブルクォートで囲む）でOK。入れなかった項目は「—」と表示されます。
> 選手は何人でも追加できます（`{ ... }` を `,` で区切って並べる）。

## 編集 → 反映の手順

1. `src/data/jbu2042Teams.json` を編集して保存
2. 変更をpush（新しいPowerShellで）:
   ```powershell
   cd C:\Users\remio\Desktop\jbu-database
   git add src/data/jbu2042Teams.json
   git commit -m "2042 チームデータ追記"
   git push origin main
   ```
3. 1〜2分後、Netlifyが再ビルドして反映

> JSONは記号（`,` `"` `{ }` `[ ]`）がずれると壊れます。編集後に不安なら、内容を貼ってもらえれば私がチェックします。
