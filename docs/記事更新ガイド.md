# JBU 記事更新システム ガイド

テキストを入力し、画像をアップロードするだけで、各シーズンの記事ページに反映される仕組みです。
構成は **Sveltia CMS（管理画面）→ GitHub（保存）→ Netlify（自動ビルド・公開）**。

---

## 仕組みの全体像

```
あなた（ブラウザ）
  https://（サイト）/admin/  ← 管理画面でテキスト入力＋画像アップ →「公開」
        │
        ▼  GitHub に自動コミット
  src/content/articles/<id>.json   （記事1本＝1ファイル）
  public/images/articles/<画像>     （アップロードした画像）
        │
        ▼  Netlify が検知して自動ビルド（1〜2分）
  サイトに反映：
    ・/articles            記事一覧
    ・/articles/<id>       記事ページ
    ・/y/<season>/articles 各シーズンの記事タブ（season の年で自動振り分け）
```

記事は1本ずつ独立したファイル（`src/content/articles/`）になっており、`season` フィールドの年で
各シーズンページへ自動的に振り分けられます。2025〜2041のNPB時代も、2042以降のMLB時代も同じ仕組みです。

## 初回セットアップ（1回だけ・PCで作業）

### 1. GitHub にアップロード

GitHub で空のリポジトリ（例 `jbu-database`）を作成してから、プロジェクトのフォルダで:

```powershell
git init
git add .
git commit -m "JBU database + 記事CMS"
git branch -M main
git remote add origin https://github.com/remiotaishi0308-cpu/jbu-database.git
git push -u origin main
```

### 2. config.yml のリポジトリ名を自分のものに変更

[public/admin/config.yml](../public/admin/config.yml) の先頭:

```yaml
backend:
  name: github
  repo: YOUR_GITHUB_USER/jbu-database   # ← 自分の「ユーザー名/リポジトリ名」に変更
  branch: main
```

変更したら再度 `git add . && git commit -m "set repo" && git push`。

### 3. Netlify でサイトを公開

1. https://app.netlify.com に GitHub アカウントでログイン（無料）。
2. **Add new site → Import an existing project → GitHub** で `jbu-database` を選択。
3. ビルド設定（自動入力されなければ手動で）:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
4. **Deploy** を押すと数分でサイトが公開されます（`https://○○○.netlify.app`）。
   - 独自ドメインも Netlify の設定から無料で割り当て可能。

### 4. 管理画面ログイン用に GitHub 認証を設定（無料・サーバー不要）

`/admin/` から GitHub アカウントで安全にログインするための設定です。

1. **GitHub OAuth アプリを作成**
   GitHub → 右上アイコン → Settings → 一番下の **Developer settings** →
   **OAuth Apps → New OAuth App**
   - Application name: `JBU CMS`（任意）
   - Homepage URL: あなたの Netlify サイトURL（例 `https://jbu.netlify.app`）
   - **Authorization callback URL**: `https://api.netlify.com/auth/done`
   - 作成後、**Client ID** を控え、**Generate a new client secret** で Secret も控える。

2. **Netlify に OAuth プロバイダを登録**
   Netlify のサイト画面 → **Site configuration → Access & security → OAuth →
   Authentication providers → Install provider → GitHub** を選び、
   上で控えた **Client ID / Client Secret** を貼り付けて保存。

これで `https://（サイト）/admin/` を開くと「GitHubでログイン」ボタンが出ます。

> 補足: Sveltia CMS は Netlify の OAuth をそのまま利用できるため、自前の認証サーバーは不要・費用ゼロです。

## 日々の使い方（記事を追加・更新する）

1. ブラウザで **`https://（あなたのサイト）/admin/`** を開く。
2. GitHub でログイン。
3. 左メニュー **「記事」→「New 記事」**。
4. 入力する:
   - **ID**: 半角英数とハイフン。記事ごとに重複しない値（例 `2041-feature-shibuya`）。URLになります。
   - **タイトル / 公開日 / シーズン（年）/ カテゴリ / リード文**
   - **サムネイル画像**: ドラッグ&ドロップでアップロード。
   - **本文**: テキスト入力。
     - 見出しは行頭に **「■ 」**（例: `■ 第1章`）。
     - 段落は **空行** で区切る。
     - 本文中の画像はツールバーの画像ボタン、またはドラッグ&ドロップで挿入。
5. **「Publish（公開）」** を押す。
6. 1〜2分後、サイトの該当シーズンの記事ページに自動反映されます。

既存記事の修正も同じく「記事」一覧から選んで編集→公開でOKです。

## ローカルでの開発・確認（任意）

```powershell
npm install      # 初回のみ
npm run dev      # 開発サーバー（記事の表示確認）
npm run build    # 本番ビルドの確認
```

記事データの実体: [src/content/articles/](../src/content/articles/) に1本=1JSONファイル。
読み込みは [src/lib/dataService.js](../src/lib/dataService.js) が `import.meta.glob` でまとめて行います。

> 旧 `src/data/articles.json` はバックアップとして残してありますが、アプリからは参照していません。
