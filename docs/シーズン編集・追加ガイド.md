# JBU シーズンデータ 編集・追加ガイド（指示書）

MLB時代（2042〜）のシーズンデータを編集・追加する手順書です。**Web管理画面(/admin)を
使わず、リポジトリ内のJSONを直接編集して push する方法**を推奨します（ブラウザ不要・確実。
AIエージェントにも適）。

---

## 0. 大原則
- データは **1シーズン = 1ファイル**：`src/data/seasons/<年>.json`（例 `2042.json`, `2043.json`）
- **最新の年が自動でサイトのトップ**になります（`src/data/seasons/` にある最大の年）。
  → 新シーズンのファイルを追加するだけで、そのシーズンがトップになります（コード変更不要）。
- 反映方法：ファイルを編集して **git push** → Cloudflare Pages が自動ビルド（1〜2分）。
- 記事は別管理：`src/content/articles/<id>.json`（1記事=1ファイル）。

---

## 1. 新しいシーズンを追加する手順
1. 最新シーズンのファイル（例 `src/data/seasons/2043.json`）を**コピー**し、
   `src/data/seasons/2044.json` として保存。
2. 先頭の `"season"` を新しい年に変更（例 `"season": 2044`）。
3. 中身（standings / teams / postseason / awards / teamStats / prospects）を新シーズンの内容に編集。
4. push（下記セクション5）。→ `/y/2044` が自動追加され、トップも2044になります。

---

### 値の注意
- チームは **`abbr`（略称）で参照**するのが確実。順位表の `team` は略称でもチーム名でもOK（部分一致で解決）。

- 数値項目（w, l, rs, ra 等）は数値、その他（gb, l10, avg 等）は文字列。
- 未入力は空文字 `""`・空配列 `[]` にしておけば、サイト側は「—」や非表示で処理します。
- **JSONの記号（`,` `"` `{}` `[]`）のズレはビルド失敗の原因**。編集後は妥当性を確認。

## 3. ロゴ・写真画像
- 画像ファイルは `public/images/articles/` に置き、パスは `/images/articles/ファイル名` で参照。
- ロゴは `teams[].logo`、ポストシーズン写真は `postseason.gallery.hero/series/recap[].url`。

---

## 4. Web管理画面(/admin)で編集する場合（任意）
- URL: `https://jbu-database.pages.dev/admin/`（GitHubログイン）
- 「シーズン (MLB 2042〜)」コレクション → 年を開いて編集、または複製/新規作成。
- ※AIエージェントに任せる場合はこの画面ではなく、**セクション2のファイル直接編集＋push** を指示すること
  （/admin はブラウザ操作が必須で、ブラウザ未接続のエージェントは操作不可）。

---

## 5. 反映（push）手順
```bash
git add -A
git commit -m "2043シーズン更新"
git push
```
1〜2分後、Cloudflare Pages が自動ビルドして `https://jbu-database.pages.dev` に反映。

### JSON妥当性チェック（push前推奨）
```bash
node -e "JSON.parse(require('fs').readFileSync('src/data/seasons/2043.json','utf8')); console.log('OK')"
```
